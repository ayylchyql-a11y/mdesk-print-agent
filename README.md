# M Desk — Agente di stampa

Programma che collega le stampanti termiche del locale agli ordini di M Desk.
Si scarica dal gestionale: **Impostazioni → Stampa → Stampanti → «Installa il programma di stampa su un computer»**.

| Computer | Programma | Istruzioni |
|---|---|---|
| Mac con chip Apple (M1–M4) | [Agente-di-stampa-arm64.dmg](Agente-di-stampa-arm64.dmg) | [IT](Istruzioni-Mac-IT.pdf) · [中文](Istruzioni-Mac-ZH.pdf) |
| Mac con processore Intel | [Agente-di-stampa-x64.dmg](Agente-di-stampa-x64.dmg) | [IT](Istruzioni-Mac-IT.pdf) · [中文](Istruzioni-Mac-ZH.pdf) |
| Windows 10 / 11 | [Agente-di-stampa-win-x64.zip](Agente-di-stampa-win-x64.zip) | [IT](Istruzioni-Windows-IT.pdf) · [中文](Istruzioni-Windows-ZH.pdf) |

Il programma è uguale per tutti i locali: il locale si collega con il codice di 6 caratteri generato nel gestionale.
